# CLAUDE.md

本文件是通用的完成定义（DoD），适用于所有语言和架构。语言级检查命令见对应的 `<lang>_check_CLAUDE.md`，架构自查项见对应的架构文件。

## 完成定义（DoD）

- [ ] 代码在正确的层和模块，依赖方向符合对应的架构文件。
- [ ] 已运行对应语言的检查命令，全部通过，并贴出真实输出。
- [ ] 新增业务分支有单元测试，覆盖失败路径；修 bug 有复现测试。
- [ ] 没有 TODO、注释掉的代码、调试日志、未使用的参数。
- [ ] 错误处理、日志、超时与中断/取消、配置方式符合对应的语言和架构文件。
- [ ] 没有新增依赖、接口、工厂或兼容层；架构要求的端口除外，新增端口对应真实 IO 边界；其他例外已在回复中说明理由。
- [ ] 已按根 `CLAUDE.md` 的「规则优先级与工作方式」格式汇报。
