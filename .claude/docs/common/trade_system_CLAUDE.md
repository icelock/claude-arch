# CLAUDE.md

本文件是实时交易系统的可选通用规则，适用于行情、订单、回报、成交等实时链路；非交易类项目不引用本文件。具体语言 API 以对应语言的 `<lang>_lang_CLAUDE.md` 和架构文件为准。

## 交易所接入

- 交易所报文、签名、限频（rate limit）、错误码只在基础设施层处理（经典分层为 infra，洋葱为出站适配器）；返回上层前转换为业务类型，不把交易所字段名带进业务层（service / application）。
- 对外接口按业务需要设计（如 `submit(HedgeOrder)`），不按交易所 API 设计（禁止 `submit(BinanceOrderRequest)`）。

## 订单幂等

- 下单使用确定性的 `clientOrderId`/`client_order_id` 作为幂等键；超时或网络错误后先按它查询订单状态再决定是否重下，禁止盲目重试。

## 行情与推送

- 行情、订单推送必须处理重复、乱序、gap、断线重连：出现 gap 时作废本地缓存并重拉快照，不能跳过继续用；重连后必须重新订阅。
- 背压分级：行情类可以丢弃并置 gap 标记；订单、回报、成交类不能丢，队列/通道（channel）满时拒绝受理或熔断，不能丢弃。
- WS/Netty 回调线程或读取循环/任务只做解析和投递：不查库、不发 HTTP、不做阻塞等待；耗时处理投递到业务线程/任务。

## 热路径

- 热路径禁止逐笔日志、字符串拼接、JSON 序列化、反射、动态分发、无界重试和不必要的对象分配/拷贝；需要这些能力时移到冷路径或做限频、缓存。
- 价格和数量按交易对的 tickSize/stepSize 显式取整；取整规则写在领域值对象/业务值对象中，舍入方向由买卖方向决定，写在代码里，不依赖默认值。
